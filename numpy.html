NumPy: The Python Calculator

What is it?

Think of NumPy as a super-fast calculator or Excel spreadsheet for Python. It stores numbers in grids (called arrays) and lets you do math on thousands of numbers instantly without writing slow loops.

How to use it

import numpy as np

# Let's make a simple list of numbers and double them!
numbers = np.array([1, 2, 3, 4, 5])
print(numbers * 2) 

# Output: [2 4 6 8 10]

Line 1: We tell Python to load the NumPy calculator and nickname it np.

Line 4: We create a grid (array) of numbers from 1 to 5.

Line 5: We instantly multiply every number inside the grid by 2. No slow loops needed!

Real-World Magic

Photo Filters: When you apply a filter to a photo on Instagram, you are using math on millions of pixels. NumPy can change the brightness of an entire photo in a fraction of a second!
